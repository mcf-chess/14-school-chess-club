# Админ хэсгийг ажиллуулах заавар

Сайтын таван хуудас ямар ч тохиргоогүйгээр ажиллана. Харин **тамирчид, зураг, амжилтыг
админаар удирдахын тулд** өгөгдөл хадгалах сервер хэрэгтэй. Энэ төсөл
[Supabase](https://supabase.com) үйлчилгээг ашиглахаар бэлтгэгдсэн.

Доорх алхмуудыг **сайтын эзэмшигч нэг удаа** хийнэ. Програмчлалын мэдлэг шаардахгүй,
20 орчим минут зарцуулна.

> **Яагаад сервер хэрэгтэй вэ?** Энгийн HTML сайт өөрөө юм хадгалж чадахгүй. Нууц үгийг
> JavaScript дотор нуух, эсвэл мэдээллийг хөтчид (`localStorage`) хадгалах нь хамгаалалт
> биш: кодыг хэн ч уншиж чадна, өгөгдөл зөвхөн таны төхөөрөмж дээр үлдэнэ. Тиймээс
> нэвтрэлт, хандах эрх, хадгалалтыг сервер хариуцна.

---

## 1. Supabase төсөл үүсгэх

1. <https://supabase.com> хаягаар орж бүртгүүлнэ (үнэгүй багц энэ сайтад хангалттай).
2. **New project** дарна. Нэр: жишээ нь `school14-chess`. Бүс: ойр байрлалыг сонгоно.
3. **Database password**-ыг үүсгээд найдвартай газар хадгална. Энэ нууц үгийг сайтын
   кодод хэзээ ч бичихгүй.

## 2. Өгөгдлийн сангийн бүтцийг үүсгэх

1. Зүүн цэснээс **SQL Editor** → **New query**.
2. Төслийн `supabase/schema.sql` файлыг нээж, бүх агуулгыг хуулж тавина.
3. **Run** дарна. «Success» гэж гарвал болсон.

Энэ файл хүснэгтүүд, хандах эрхийн дүрэм, зургийн савыг үүсгэнэ. Дахин ажиллуулахад
аюулгүй: байгаа өгөгдлийг устгахгүй.

## 3. Гадны хүн бүртгүүлэхийг хаах

1. **Authentication** → **Sign In / Providers** (эсвэл **Settings**).
2. **Allow new users to sign up** тохиргоог **унтраана**.

Ингэснээр зөвхөн таны гараар үүсгэсэн хэрэглэгч нэвтэрнэ. (Унтраагаагүй байсан ч
бүртгүүлсэн гадны хүн юу ч өөрчилж чадахгүй — 5-р алхмыг үзнэ үү. Гэхдээ унтраах нь зөв.)

## 4. Админ хэрэглэгч үүсгэх

1. **Authentication** → **Users** → **Add user** → **Create new user**.
2. Админы имэйл болон **урт, давтагдашгүй нууц үг** оруулна (12-оос дээш тэмдэгт).
3. **Auto Confirm User**-ийг тэмдэглээд **Create user** дарна.

## 5. Тэр хэрэглэгчийг админы жагсаалтад нэмэх

Supabase-д бүртгэлтэй байх нь админ гэсэн үг биш. Зөвхөн `admins` хүснэгтэд байгаа
хэрэглэгч мэдээлэл өөрчилж чадна.

**SQL Editor**-т доорхыг ажиллуулна (имэйлээ солино):

```sql
insert into public.admins (user_id, note)
select id, 'Клубын админ'
from auth.users
where email = 'ТАНЫ-АДМИН-ИМЭЙЛ@example.com';
```

«Success. 1 row» гэвэл болсон. Өөр админ нэмэх бол 4, 5-р алхмыг давтана.

Админы эрхийг хасах:

```sql
delete from public.admins
where user_id = (select id from auth.users where email = 'ХАСАХ-ИМЭЙЛ@example.com');
```

## 6. Сайтыг сервертэй холбох

1. **Project Settings** → **API** (эсвэл **API Keys**).
2. Хоёр утгыг хуулна:
   - **Project URL** — `https://xxxxxxxx.supabase.co` хэлбэртэй
   - **anon public** түлхүүр (шинэ төсөлд **Publishable key** гэж нэрлэгдэнэ)
3. Төслийн `js/backend-config.js` файлыг нээж бөглөнө:

```js
const BACKEND_CONFIG = {
  url: 'https://xxxxxxxx.supabase.co',
  anonKey: 'энд anon / publishable түлхүүр',
};
```

> **Анхаар.** `anon` / `publishable` түлхүүр нь хөтөч дээр ил байхаар зориулагдсан тул
> кодод бичиж болно. Харин **`service_role` / `secret` түлхүүрийг хэзээ ч бүү тавь** —
> тэр түлхүүр бүх хамгаалалтыг тойрдог. Админы имэйл, нууц үг, өгөгдлийн сангийн нууц
> үгийг мөн кодод бичихгүй.

## 7. Сайтыг байршуулж шалгах

1. Хавтсыг бүхэлд нь хостингдоо (GitHub Pages, Netlify г.м.) байршуулна.
2. `https://таны-сайт/admin.html` хаягаар орж 4-р алхмын имэйл, нууц үгээр нэвтэрнэ.
3. Туршилтын тамирчин нэмээд **ноорог** хэвээр хадгална. `athletes.html` дээр
   **харагдахгүй** байгааг шалгана.
4. Зөвшөөрлийг тэмдэглэж нийтлээд `athletes.html` дээр **харагдаж** байгааг шалгана.
5. Туршилтын бүртгэлээ устгана.

Сайтын домэйн тогтсоны дараа **Authentication** → **URL Configuration** → **Site URL**-д
сайтынхаа хаягийг оруулаарай.

## Админ хэсгийг хэрхэн ашиглах вэ

`admin.html` хуудаст (хөл хэсгийн «Админ» холбоос) нэвтэрнэ.

### Сайт дээрээс шууд засах

`admin.html`-д нэвтэрсний дараа сайтын аль ч хуудсыг **тэр табдаа** нээхэд дээд талд
хөх өнгийн **«Админ горим»** мөр гарна («Админ хэсэг», «Гарах» холбоостой).

**Тамирчид** хуудсанд админд:

- ноорог болон нийтэлсэн **бүх** тамирчин, амжилт харагдана. Ноорог карт тасархай хүрээтэй,
  «Ноорог», «Зөвшөөрөл аваагүй» гэх мэт тэмдэгтэй;
- карт бүрт **Засах**, **Нийтлэх / Нийтлэхээ болих**, **Амжилт нэмэх**, **Устгах** товч;
- хэсэг бүрийн дээр **Шинэ тамирчин нэмэх**, **Шинэ амжилт нэмэх** товч гарна.

**Засах** дарахад админ хуудасны маягт тэр бүртгэл дээр нээгдэж, хадгалах эсвэл болиход
тамирчдын хуудас руу буцна. Зочид энэ товчнуудыг харахгүй, «Гарах» дарахад сайт зочны
харагдац руу шилжинэ. Нэвтрэлт таб хаахад дуусна.

Сургалтын хуваарь, төлбөр, багш нарын танилцуулга зэрэг бусад хуудасны бичвэр өгөгдлийн
санд биш, HTML файлд (`js/site-config.js` болон `*.html`) байдаг тул сайт дээрээс засагдахгүй.

### Тамирчин нэмэх

1. **+ Шинэ тамирчин** дарна.
2. Овог нэр (заавал), анги, анги хариуцсан багш, цол, чансааг бөглөнө. Байхгүй цол,
   чансааг хоосон орхино — сайт дээр тэр мөр харагдахгүй.
3. **Зураг сонгох** дарж JPEG, PNG эсвэл WebP зураг (8 MB хүртэл) сонгоно. Урьдчилсан
   харагдац гарна. Зураг хадгалахын өмнө автоматаар жижгэрнэ.
4. **Зөвшөөрөл ба нийтлэл** хэсэг:
   - «Нэр, анги, цол, амжилтыг нийтлэх зөвшөөрөл авсан» — эцэг эх, асран хамгаалагчаас
     зөвшөөрөл авсны дараа л тэмдэглэнэ. Тэмдэглээгүй бол нийтлэх боломжгүй.
   - «Зургийг нийтлэх зөвшөөрөл авсан» — тэмдэглээгүй бол зураг хадгалагдсан ч сайт
     дээр харагдахгүй.
   - «Сайтад нийтлэх» — тэмдэглэвэл олон нийтэд харагдана, тэмдэглээгүй бол ноорог.
5. **Хадгалах** дарна. Дээд хэсэгт ногоон мэдэгдэл гарвал амжилттай.

### Гол амжилтууд

Тамирчны маягтын **Гол амжилтууд** хэсэгт хамгийн том 2–3 амжилтыг (тэмцээний нэр, үр дүн,
огноо) шууд бичнэ. Эдгээр нь тамирчны картан дээр «Гол амжилт» гарчигтай харагдана.

- Тэмцээний нэр ба үр дүнг хоёуланг нь бөглөнө. Огноо заавал биш (картанд жил нь гарна).
- Мөрийг хоосолбол амжилт устахгүй, зөвхөн картнаас хасагдаж «Тэмцээний амжилт» жагсаалтад үлдэнэ.
- «Тэмцээний амжилт» таб дахь маягтаас ч «Гол амжилт» гэж тэмдэглэж болно. Нэг тамирчинд 3 хүртэл.
- Гол амжилт тэмдэглээгүй тамирчны картанд сүүлийн 3 амжилт нь гарна.

> **Өмнө нь үүсгэсэн өгөгдлийн санд** энэ боломжийг ашиглахын өмнө **SQL Editor**-т
> `supabase/schema.sql`-ийг дахин ажиллуулна (байгаа өгөгдлийг устгахгүй).

### Засах, нийтлэх, устгах

- Жагсаалтын мөр бүрт **Засах**, **Нийтлэх / Нийтлэхээ болих**, **Устгах** товч бий.
- **Тамирчин хайх** талбарт нэр, анги эсвэл багшийн нэрээр хайна.
- **Устгах** дарахад баталгаажуулах цонх гарна. Тамирчныг устгахад түүний бүх амжилт,
  зураг хамт устана. Буцаах боломжгүй.

### Тэмцээний амжилт

1. **Тэмцээний амжилт** таб → **+ Шинэ амжилт**.
2. Тамирчнаа сонгож, тэмцээний нэр, үр дүн (заавал), огноо, товч тайлбар оруулна.
3. «Сайтад нийтлэх»-ийг тэмдэглээд хадгална.

Амжилт нь **тамирчин өөрөө нийтлэгдсэн** үед л олон нийтэд харагдана.

## Хамгаалалт хэрхэн ажилладаг вэ

| Хэн                                   | Юу хийж чадах вэ                                                        |
| ------------------------------------- | ----------------------------------------------------------------------- |
| Сайтын зочин (нэвтрээгүй)             | Зөвхөн нийтэлсэн, зөвшөөрөл баталгаажсан тамирчин, амжилт, зургийг үзнэ |
| Supabase-д бүртгэлтэй ч админ биш хүн | Зочинтой адил. Юу ч нэмж, засаж, устгаж чадахгүй                        |
| `admins` жагсаалтад байгаа хэрэглэгч  | Бүх бүртгэлийг үзэж, нэмж, засаж, нийтэлж, устгана                      |

- Эдгээр дүрмийг **сервер** мөрдүүлнэ (`supabase/schema.sql` дахь Row Level Security).
  Хөтөч дээрх JavaScript-ийг өөрчилсөн ч тойрч чадахгүй.
- Зөвшөөрөл тэмдэглээгүй тамирчныг нийтлэхийг сервер өөрөө татгалзана.
- Ноорог бүртгэл, зөвшөөрөлгүй зураг зочны хөтөч рүү **огт илгээгдэхгүй**.
- Зургууд хувийн саванд хадгалагдана: 2 MB хүртэл, зөвхөн JPEG / PNG / WebP.
- Нууц үг хөтөчид хадгалагдахгүй. Нэвтэрсний дараах түр токен таб хаахад устана.

## Туршсан ба туршаагүй зүйл

Энэ кодыг хүлээлгэж өгөхөөс өмнө `supabase/schema.sql`-ийг жинхэнэ PostgreSQL 16 дээр
ажиллуулж, хандах эрхийн дүрмийг 30 шалгалтаар, админ хуудасны бүх үйлдлийг хөтөч дээр
56 шалгалтаар туршсан.

**Гэхдээ жинхэнэ Supabase төсөлтэй холбож туршаагүй** (данс, сүлжээний холболт байгаагүй).
Туршилтад Supabase-ийн HTTP хаягуудыг дуурайсан сервер ашигласан. Иймээс 7-р алхмын
шалгалтыг заавал хийнэ үү. Хэрэв нэвтрэх эсвэл зураг хадгалах үед алдаа гарвал хөтчийн
консол (F12) дээрх мэдээллийг хөгжүүлэгчид үзүүлээрэй.

## Түгээмэл асуудал

| Харагдах байдал                                    | Шалтгаан, шийдэл                                                                              |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| «Өгөгдлийн сервер холбогдоогүй байна»              | `js/backend-config.js` хоосон байна (6-р алхам)                                               |
| «Имэйл эсвэл нууц үг буруу байна»                  | 4-р алхмын хэрэглэгчийг шалгана. «Auto Confirm» тэмдэглэсэн эсэх                              |
| «Энэ хэрэглэгч админы жагсаалтад бүртгэгдээгүй…»   | 5-р алхмыг хийгээгүй эсвэл имэйл буруу бичсэн                                                 |
| «Сервертэй холбогдож чадсангүй»                    | Интернэт холболт, эсвэл `url` буруу. Үнэгүй төсөл удаан ашиглаагүй бол түр зогсож болно: Dashboard-оос сэргээнэ |
| Нийтэлсэн тамирчин сайт дээр харагдахгүй           | Мэдээлэл нийтлэх зөвшөөрөл тэмдэглэгдсэн эсэх; хуудсаа дахин ачаална                          |
| Зураг сайт дээр харагдахгүй                        | «Зургийг нийтлэх зөвшөөрөл авсан» тэмдэглэгдээгүй                                             |

## Нөөцлөлт

Supabase Dashboard → **Table Editor** → `athletes`, `achievements` хүснэгт тус бүрээс
**Export to CSV** хийж улиралд нэг удаа хадгалаарай.

## Онлайн бүртгэл ба сарын төлбөр

- Эцэг эх «Холбоо барих» хуудасны маягтаар бүртгүүлнэ. Дансны мэдээлэл, төлөх дүн зөвхөн
  бүртгүүлсний дараа гарна. Гүйлгээний утга: хүүхдийн овог нэр + эцэг эхийн утас.
- Сарын төлбөр: 14-р сургуулийн сурагч 100,000₮, бусад сургуулийн сурагч 250,000₮. Дүнг сервер
  (`supabase/schema.sql`, `submit_registration`) тогтооно. Өөрчлөх бол тэнд болон
  `js/site-config.js`-д хоёуланд нь засна. Хүүхэд бүрийн дүнг админ «Засах»-аар өөрчилж болно.
- Төлбөрийн сар бүртгүүлсэн өдрөөс тоологдоно: 11/22-нд эхэлсэн бол 11/22–12/21 эхний сар,
  дараагийн төлбөр 12/22. Эхэлсэн өдрийг админ «Засах»-аар өөрчилж болно.
- Төлбөрийг дансаар шилжүүлнэ. Сайт мөнгө хүлээн авахгүй.
- Дансны мэдээлэл (банк, данс, IBAN) `js/site-config.js` доторх `bank` хэсэгт байна.
- Админ хэсгийн «Бүртгэл, төлбөр» табаас банкны хуулгад орсон нэр эсвэл утсаар хайж
  «Төлбөр баталгаажуулах» дарж аль сарын төлбөр болохыг сонгоно. Хэн, хэзээ баталгаажуулсан нь
  хадгалагдана. «Төлөх хугацаа болсон» шүүлтүүр төлбөр сануулах хүүхдүүдийг харуулна.
- Хүүхдийн мэдээлэл олон нийтэд харагдахгүй.
- Өгөгдлийн сангийн бүтэц: `supabase/schema.sql`-ийн 7-р хэсэг.
