# 14 дүгээр сургуулийн шатрын клуб — вэб сайт

Энгийн HTML, CSS, JavaScript-ээр бичсэн таван хуудастай сайт. Build алхам, Node.js,
гаднын сан шаардахгүй: хавтсыг тэр чигээр нь хостингд байршуулахад ажиллана.

Тамирчид, зураг, амжилтыг админаар удирдах хэсэг нь Supabase гэх өгөгдлийн серверт
холбогдоно. Тохируулах алхмуудыг **[ADMIN-SETUP.md](ADMIN-SETUP.md)**-ээс үзнэ үү.
Сервер тохируулаагүй үед таван хуудас хэвийн ажиллаж, тамирчдын хэсэг «удахгүй» гэж харагдана.

## Нээх

- `index.html`-ийг давхар товшиж браузераар нээнэ, эсвэл
- VS Code-д хавтсаа нээгээд `index.html` → **Open with Live Server**.

| Файл            | Агуулга                                                                    |

### Утас, имэйл, цаг өөрчлөх

`js/site-config.js` дотор нэг газар засахад бүх хуудсанд шинэчлэгдэнэ.

HTML файлууд доторх утга нь JavaScript ажиллахгүй үед (маш ховор) харагдах **нөөц хувилбар**
юм. Мэдээлэл өөрчлөгдвөл VS Code-ийн **Find in Files** (`Ctrl+Shift+F`)-ээр хуучин утгыг
хайж, HTML доторхыг мөн солиорой. Хуудас бүрийн `<meta name="description">` болон
хуваарийн картуудын доорх тайлбар бичвэрийг HTML дотроос засна.

## Хүртээмж, JavaScript-гүй үед

- Хуудас бүр «Үндсэн агуулга руу шилжих» холбоостой, гараар бүрэн удирдагдана.
- Сургалтын түвшнүүд HTML дээр `<details>` хэлбэртэй. JavaScript ажиллахад таб болж
  хувирна; ажиллахгүй бол нээгдэж хаагддаг жагсаалт хэвээр үлдэж, бүх агуулга уншигдана.
- JavaScript-гүй үед гар утасны цэс үргэлж нээлттэй харагдана.
- Шатрын бодлого болон тамирчдын жагсаалт JavaScript шаарддаг; үгүй бол тайлбар бичвэр гарна.
- Хөдөлгөөн багасгах тохиргоог (`prefers-reduced-motion`) дагана.

## Шатрын бодлого

Хөлөг нүүдлийг хадгалсан хариуттай тулгаж биш, **шатрын дүрмээр** шалгана
(`js/chess-rules.js`): дүрс зөв хэлбэрээр нүүсэн эсэх, замд саад байгаа эсэх, нүүсний
дараа өөрийн ноён шахад үлдэх эсэх, эцэст нь хар ноён үнэхээр мат болсон эсэх.

Хариу гурван төрөл: дүрмийн бус нүүдэл (шалтгаантай), дүрмийн дагуу боловч мат биш
(хар хэрхэн аврагдахыг хэлнэ), мат.

Бодлого нэмсэн эсвэл өөрчилсний дараа:

```
node tests/puzzles.test.js
```

Энэ нь бодлого бүрийн шийдэл үнэхээр мат бөгөөд цорын ганц мат болохыг шалгана.
Сэлгээ, замд авах, хүү хувирах дүрмийг дэмжихгүй (нэг нүүдлийн матын бодлогод хэрэггүй).

## Код форматлах

`.prettierrc.json` тохиргоо бий. VS Code-д Prettier өргөтгөл суулгасан бол файлаа хадгалах
бүрт ижил хэв маягаар форматлагдана.

## Интернэтэд гаргах

1. `ADMIN-SETUP.md`-ийн дагуу Supabase-ийг тохируулж `js/backend-config.js`-ийг бөглөнө
   (админ хэсэг хэрэггүй бол алгасаж болно).
2. Хавтсыг бүхэлд нь GitHub Pages, Netlify эсвэл ямар ч энгийн хостинг руу оруулна.
   Бүх зам харьцангуй тул дэд хавтсанд байрлуулсан ч ажиллана.
3. Заавал **HTTPS**-тэй хостинг ашиглана: админ нэвтрэлт шифрлэгдсэн холболтоор явах ёстой.

### Git-д юу оруулж болох вэ

- `js/backend-config.js` дахь **anon / publishable** түлхүүр нийтийнх тул оруулж болно.
- **service_role / secret** түлхүүр, өгөгдлийн сангийн нууц үг, админы нууц үгийг хэзээ ч
  кодод бичихгүй, Git-д оруулахгүй.
